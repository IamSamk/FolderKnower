Why Architekton?

🔒

100 % offline

Your code never leaves the machine. Static analysis only — no AI cloud, no uploads, no telemetry.

⚡

Seconds, not minutes

Rust + tree-sitter parse thousands of files in a fraction of a second. SQLite caches incremental updates.

🗺

Architecture → down to functions

Navigate from system tiers to subsystems, files, call graphs, REST routes and the ER diagram — all in one view.

🎨

Beautiful by default

Soft neo-brutalist UI with light / dark / system themes. ELK auto-layout. Animated portal transitions.

🤖

Optional local AI

Plug in Ollama or llama.cpp to explain architecture decisions in plain language — still fully offline.

📦

CLI included

Export architecture.json from any CI pipeline with architekton index <repo>. Same deterministic output.
