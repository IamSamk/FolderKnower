2. Privacy

Architekton runs entirely on your computer. It does not upload, share or send
your code, file names, analysis results or usage data anywhere. There is no
account, no analytics and no telemetry.

It keeps a cache of parsed results in your user cache folder to speed up later
runs. You can delete that folder at any time.

3. Optional local AI components

The AI features are optional and are not installed by this installer. If you
turn them on in the app, Architekton downloads these files once, verifies their
SHA-256 checksums, and runs them on 127.0.0.1 (this computer only):

- llama.cpp (llama-server), MIT License,
  https://github.com/ggml-org/llama.cpp
- Laya decision model (GGUF by ggml-org), Apache License 2.0,
  https://huggingface.co/convaiinnovations/laya
- Qwen2.5-0.5B-Instruct (GGUF), Apache License 2.0, Copyright Alibaba Cloud,
  https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct

Each component is subject to its own license, linked above.
